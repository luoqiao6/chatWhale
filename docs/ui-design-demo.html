好的，以下是一个完整的示例，演示如何通过 chatWhale 的 Tool Calls 功能让模型自动调用外部工具：

pythonimport os
import json
from openai import OpenAI
from datetime import datetime

def get_weather(location: str, date: str) -> str:
    """模拟天气查询"""
    return f"{location} {date}: 多云 28~36°C"

TOOLS = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询指定城市天气",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"},
                "date": {"type": "string"}
            },
            "required": ["location"]
        }
    }
}]

client = OpenAI(
    api_key="your-api-key",
    base_url="http://localhost:8080/v1"
)

messages = [{"role": "user", "content": "杭州明天天气？"}]

while True:
    resp = client.chat.completions.create(
        model="deepseek-v4-pro",
        messages=messages,
        tools=TOOLS,
        extra_body={"thinking": {"type": "enabled"}}
    )
    msg = resp.choices[0].message
    messages.append(msg)
    if msg.tool_calls is None:
        break  # 模型给出最终答案
    for tc in msg.tool_calls:
        args = json.loads(tc.function.arguments)
        result = get_weather(**args)
        messages.append({
            "role": "tool",
            "tool_call_id": tc.id,
            "content": result
        })

print(msg.content)

这段代码展示了 Tool Calls 的完整循环：模型决定调用哪个函数 → 用户侧执行 → 结果回传给模型 → 模型生成最终答案。思考模式下，reasoning_content 也会在每轮中正确回传。
