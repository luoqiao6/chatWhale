# 列出模型

GET https://api.deepseek.com/models
列出可用的模型列表，并提供相关模型的基本信息。请前往模型 & 价格查看当前支持的模型列表

## Responses​

OK, 返回模型列表

- **Schema**
  - **data** `Model[]` *required*
    - **id** `string` *required*
      模型的标识符
    - **object** `string` *required*
      Possible values: [model]
    - **owned_by** `string` *required*
      拥有该模型的组织。
    对象的类型，其值为 model。
  - **object** `string` *required*
    Possible values: [list]

```json
{
  "object": "list",
  "data": [
    {
      "id": "string",
      "object": "model",
      "owned_by": "string"
    }
  ]
}
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "deepseek-v4-flash",
      "object": "model",
      "owned_by": "deepseek"
    },
    {
      "id": "deepseek-v4-pro",
      "object": "model",
      "owned_by": "deepseek"
    }
  ]
}
```
